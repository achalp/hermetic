# Archived specs

Historical design records kept for provenance — **not** current documentation.

Each file here is one of:

- an **implementation plan whose work has shipped** (the April/May Tier-1 and
  agentic-Tier-1 plans and their `testing/` test plans),
- an **early exploratory design overtaken by reality** (`DESIGN-SPEC.md`,
  `IMPLEMENTATION-PLAN.md`, `spec.md`, `home-prototypes-2026-07-31/`),
- a **direction that was superseded** (`published-artifacts-sharing-2026-06-17.md`
  → shipped as `../dashboard-distribution-2026-08-05.md`;
  `metadata-mode-privacy.md` → the compose pipeline), or
- a **transient working note** no longer maintained (`fixes.md`,
  `review-follow-ups-2026-07-08.md`, `state-persistence.md`).

For the current design records, see the dated specs one level up in `specs/`.
Cross-links between files in this folder are self-contained (they moved here
together); a handful of live specs and comparison notes were updated to point
at these new paths.
